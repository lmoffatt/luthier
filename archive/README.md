# Archive

What Luthier had before the specification of 2026-10-04 (`docs/semantica/04-kernel.md`,
`05-static-semantics.md`). The libraries, examples and interpreter tests here are written in the
syntax and under the rules of the interpreter tagged `v0-pre-spec`; they are kept as the source
the new libraries are rewritten from, not as code that runs on the current interpreter.

- `lib-2026-10-04/`: the shipped libraries (real, random, peano, algebra, array, table) and their
  certificates.
- `examples-2026-10-04/`: the examples of the README of that time.
- `tests-2026-10-04/`: the interpreter tests that loaded those libraries.
