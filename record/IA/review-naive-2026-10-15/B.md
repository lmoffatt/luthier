12. `src/luthier/host.py`, lines 33-40 (`text_of_bytes`). The map from bytes to string is not injective: `b"\xc3\xa9"` decodes as UTF-8 to `"é"` and `b"\xe9"` is invalid UTF-8 and decodes as Latin-1 to the same `"é"`. Also, `\r\n` and `\r` become `\n` for any file that is valid UTF-8, binary ones included, so a PNG that happens to be valid UTF-8 (rare, but a small binary can be) is altered, and two files that differ only in line endings read the same. The hash of "what was read" (10.S9) would then be taken over a string that does not identify the bytes. `agreement` cannot see these differences either. Change: decide per extension or per declared type (String vs Bytes), or keep the bytes as a latin-1 string always for non-text, and compute the hash over the raw bytes before decoding.

14. `src/luthier/host.py`, lines 14-15, 47-50 and 87-90.
